# ✊ Rock Paper Scissors Game ✋ ✌️

A simple, fun, and interactive **Rock Paper Scissors** web game built with Vanilla JavaScript, HTML5, and CSS3. Play against the computer and track your score in real time!

---

## 🎮 Features

- **Interactive Gameplay:** Click on Rock, Paper, or Scissors icons to make your move.
- **Computer AI:** Generates random moves automatically.
- **Live Scoreboard:** Tracks wins for both User and Computer.
- **Dynamic Feedback:** Instant colored message alerts:
  - 🟢 **Green:** You Win!
  - 🔴 **Red:** You Lose!
  - 🟠 **Orange:** Game is a Draw!

---

## 📜 Game Rules

- **Rock** beats **Scissors** (Rock crushes Scissors)
- **Scissors** beats **Paper** (Scissors cut Paper)
- **Paper** beats **Rock** (Paper covers Rock)
- Same choices result in a **Draw**.

---

## 🛠️ Built With

- **HTML5:** Game structure & layout
- **CSS3:** Styling, animations & responsive design
- **JavaScript (ES6):** Game logic & DOM manipulation
